# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Is

`sd-talk` is an offline voice chat system for Steam Deck. Pipeline: mic → whisper.cpp (STT) → llama-server (LLM) → Piper (TTS) → speaker. Everything runs 100% locally.

## Files

- `sd-talk.sh` — main entry point (record → transcribe → LLM → speak loop)
- `setup.sh` — one-time setup: downloads Piper binary + voice model
- `config.example` — template for `~/.config/sd-talk/config`

## First-Time Setup

```bash
./setup.sh                    # downloads Piper, installs config
```

## Running

```bash
./sd-talk.sh
```

Press Enter to start recording, Enter again to stop. Ctrl+C to quit.

## Component Locations (on this machine)

| Component | Path |
|-----------|------|
| whisper-cpp binary | `~/bin/whisper-cpp` (static, built in arch-build container) |
| whisper model | `~/.local/share/whisper/ggml-base.bin` |
| llama-server | `~/llama.cpp/build/bin/llama-server` (runs in `llama.cpp` distrobox) |
| LLM models | `~/llama.cpp/models/` (qwen2.5-{3b,4b,7b}-q4.gguf) |
| Piper binary | `~/.local/share/sd-talk/piper/piper` (after setup.sh) |
| Piper models | `~/.local/share/sd-talk/piper/models/` (after setup.sh) |

## LLM Server

`sd-talk.sh` auto-starts `llama-server` inside the `llama.cpp` distrobox container on port 8080, using `HSA_OVERRIDE_GFX_VERSION=10.3.0` for Vulkan GPU acceleration on the Van Gogh APU. The server exposes an OpenAI-compatible `/v1/chat/completions` endpoint.

To inspect logs if the server fails to start:
```bash
distrobox enter llama.cpp -- cat /tmp/llama-server.log
```

## Dependencies

Host (SteamOS): `pw-record`, `pw-play` (PipeWire — already present), `curl`, `jq`

Install jq if missing:
```bash
sudo pacman -S jq      # survives until next SteamOS update — add to ~/bin workaround if needed
```

## Config

User config at `~/.config/sd-talk/config` (generated by `setup.sh`). Key options: `WHISPER_LANG`, `LLM_MODEL`, `PIPER_MODEL`, `SYSTEM_PROMPT`, `CONVERSATION_TURNS`.
